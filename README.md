# Photo Rock Observation Kit

Reusable, plain-text templates for documenting a rock or mineral specimen from photographs without treating a photograph as laboratory proof.

## Contents

| File | Use |
| --- | --- |
| rock-photo-observation-template.md | A field-note worksheet for one specimen. |
| observation-fields.csv | The same fields in a format that can be imported into a spreadsheet or form. |
| evidence-check-order.md | A non-destructive order for checking a tentative photo-based identification. |

## Use

1. Start with a whole-specimen photograph in even light.
2. Write only what is visible before recording a possible name.
3. Keep discovery setting separate from identification: context can support a comparison, but does not prove composition.
4. Record uncertainty when the photo cannot settle a feature.

These templates are intended for learning and documentation. They do not measure hardness, density, composition, crystal structure, provenance, or value. Do not use a photo result to certify a meteorite, appraise a specimen, or assess an unknown hazardous material.

The templates support the cautious photo-identification workflow at [FIELD / ROCK ID](https://rockidnow.com/).
